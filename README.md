# Somat Adhikari Portfolio

A new editorial-style architecture portfolio starter built with Next.js and Tailwind CSS.

## Included
- Homepage with featured projects
- Projects index with category filters
- Individual project case-study routes
- About, Expertise and Contact pages
- Project content transcribed from the supplied 47-page portfolio PDF
- Selected source-PDF page renders included as temporary visual assets

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Deploy to GitHub and Vercel
1. Create a new GitHub repository.
2. Upload/push the contents of this folder to the repository.
3. In Vercel, choose **Add New → Project** and import the GitHub repository.
4. Keep the framework preset as Next.js and deploy.
5. Future pushes to the connected branch will trigger deployments.

## Important before public launch
- Replace the temporary full-page portfolio images in `public/images/portfolio-pages/` with clean, original project renders, drawings and photographs.
- Confirm biography, education, employment history, current professional title, contact details and LinkedIn.
- Confirm project dates, roles and areas where the source PDF is unclear or inconsistent.
- Add a real CV PDF if a downloadable CV is required.
- Configure a contact-form provider or email endpoint before enabling a working enquiry form.

The current image files are page renders from the supplied PDF, used only to make the starter site visually navigable. They are not ideal final website imagery. Replace them with original high-resolution project assets before publication.
